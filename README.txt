САЙТ — СЕРВИС УДАЛЁННЫХ АССИСТЕНТОВ
Как выложить на Vercel

ЧТО ВНУТРИ
index.html       — главная страница, полная версия (компьютеры, ноутбуки, планшеты)
mobile.html      — мобильная версия (телефоны)
*.dc.html        — блоки сайта, из которых собираются обе версии
support.js       — скрипт, который отрисовывает блоки
assets/          — логотипы клиентов, фото, иконка сайта, картинка для превью ссылки
vercel.json      — служебная настройка для Vercel

КАК ЗАГРУЗИТЬ ИЛИ ОБНОВИТЬ САЙТ
1. Распакуйте архив и откройте папку teamboss-site.
2. На GitHub откройте репозиторий сайта → Add file → Upload files.
3. Перетащите ВСЁ СОДЕРЖИМОЕ папки (файлы и папку assets, но не саму папку teamboss-site).
4. Нажмите Commit changes. Через минуту Vercel сам обновит сайт.
5. Откройте сайт и обновите страницу без кэша: Ctrl+Shift+R (Windows) или Cmd+Shift+R (Mac).

КАК РАБОТАЮТ ЗАЯВКИ
Все кнопки заявок открывают чат с вами в Telegram (@boriseyshestvo) с уже заполненным сообщением:
ответы из анкеты, отмеченные задачи, контакты. Клиенту остаётся нажать «Отправить».
Бот и настройки в Vercel для этого не нужны. Если раньше вы загружали папку api, её можно удалить
из репозитория — она больше не используется.

КАК РАБОТАЕТ ВЫБОР ВЕРСИИ
- Главный адрес открывает полную версию. На телефоне и в узком окне (уже 960 пикселей)
  страница сразу переключается на мобильную версию — /mobile.html.
- На широком экране мобильная версия сама возвращает на главную.

СВОЙ ДОМЕН
Vercel → проект → Settings → Domains → добавить домен и прописать DNS-записи, которые покажет Vercel.
