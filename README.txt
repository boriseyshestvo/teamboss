САЙТ — СЕРВИС УДАЛЁННЫХ АССИСТЕНТОВ
Как выложить на Vercel и получать заявки в Telegram

ЧТО ВНУТРИ
desktop.html     — полная версия (компьютеры, ноутбуки, планшеты)
mobile.html      — мобильная версия (телефоны)
*.dc.html        — блоки сайта, из которых собираются обе версии
support.js       — скрипт, который отрисовывает блоки
api/lead.js      — пересылает заявки с сайта вам в Telegram
assets/          — логотипы клиентов, фото, иконка сайта, картинка для превью ссылки
vercel.json      — настройка: телефоны автоматически получают мобильную версию

ШАГ 1. ВЫЛОЖИТЬ САЙТ (через GitHub, без программирования)
1. Распакуйте архив.
2. На github.com создайте новый репозиторий (New repository, можно Private).
3. Нажмите «uploading an existing file» и перетащите ВСЁ СОДЕРЖИМОЕ папки teamboss-site
   (файлы и папки api и assets, но не саму папку). Нажмите Commit changes.
4. На vercel.com войдите через GitHub → Add New → Project → выберите репозиторий →
   Framework Preset: Other → Deploy.
5. Через минуту сайт будет по адресу вида название-проекта.vercel.app.

ШАГ 2. ПОДКЛЮЧИТЬ ЗАЯВКИ В TELEGRAM (5 минут)
1. В Telegram откройте @BotFather → команда /newbot → придумайте название
   (например «Заявки с сайта») и имя бота, которое заканчивается на bot.
   BotFather пришлёт токен — длинную строку вида 1234567890:AAH... Никому её не показывайте.
2. Найдите своего нового бота в поиске Telegram и нажмите «Запустить» (Start).
   Без этого бот не сможет вам писать.
3. Узнайте свой числовой Telegram ID: напишите боту @userinfobot — он ответит строкой Id.
   (Если хотите, чтобы заявки приходили в общую группу с командой: добавьте бота в группу,
   а ID группы узнайте тем же способом — у групп он начинается с минуса.)
4. Vercel → ваш проект → Settings → Environment Variables. Добавьте две переменные:
   TELEGRAM_BOT_TOKEN = токен из шага 1
   TELEGRAM_CHAT_ID   = ID из шага 3
   Сохраните.
5. Vercel → Deployments → у последней публикации меню «…» → Redeploy.
6. Отправьте тестовую заявку с сайта — она придёт вам от бота.

Если что-то не настроено, сайт покажет посетителю сообщение
«Не получилось отправить заявку» и предложит написать вам в Telegram — заявка не потеряется молча.

КАК РАБОТАЕТ ВЫБОР ВЕРСИИ
- Главный адрес сам определяет устройство: телефон получает мобильную версию,
  компьютер, ноутбук и планшет — полную.
- Если полную версию открыть в узком окне (уже 960 пикселей), она переключится на мобильную.
- Для проверки обе версии открываются напрямую: /desktop и /mobile.

КАК ОБНОВЛЯТЬ
Замените изменённые файлы в репозитории GitHub — Vercel сам обновит сайт по тому же адресу.

СВОЙ ДОМЕН
Vercel → проект → Settings → Domains → добавить домен и прописать DNS-записи, которые покажет Vercel.
